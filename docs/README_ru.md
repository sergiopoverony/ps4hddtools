# ps4hddtools 1.2.0.12

Payload (ELF) для PS4 (прошивка 13.52, GoldHEN): состояние диска (SMART) и проверка поверхности. Веб-интерфейс открывается в браузере: `http://<IP консоли>:8686/`.

Created by SergioPoverony and Mr.Claude. Лицензия GPLv3.

## Как пользоваться
1. Отправьте `ps4hddtools.elf` на консоль (BinLoader, порт 9090) или поставьте в автозагрузку GoldHEN.
2. Откройте в браузере `http://192.168.0.24:8686/` (свой IP консоли).
3. Вверху вкладки дисков: внутренний, USB (USB0…) и расширенное хранилище (EXT0). На вкладке имя диска и состояние: «Здоров», «Внимание», «Плохо».
4. Слева подробный SMART выбранного диска. Справа проверка поверхности.
5. Проверка: поля «С/По (ГБ)» (по умолчанию весь диск), кнопка «Старт». Перед запуском программа замеряет скорость и показывает ожидаемое время, нужно подтвердить. Есть «Пауза», «Продолжить» и «Стоп».
6. Пока идёт проверка, консоль не уходит в спящий режим.
7. Красная кнопка «Выключить» останавливает программу.

## Что важно знать
* Диску посылаются только команды чтения. Ничего не записывается и не стирается.
* В покое программа ничего не делает и не использует память. Диски и SMART читаются, когда вы открываете страницу или нажимаете «Обновить диски».
* Одновременно выполняется одна операция.
* Повторный запуск payload сам просит старую копию завершиться.
* Цвета карты: зелёный (быстро) → жёлтый → оранжевый → красный (медленно) → тёмно-красный (ошибка чтения). Счётчики по каждому цвету под картой.
* Если в блоке найдена ошибка, он перечитывается по секторам; первые 100 проблемных LBA показываются под картой.
* Проверка разделов (da0x*) убрана из интерфейса: настоящей проверки пока нет.

## Сборка
```
export PS4_PAYLOAD_SDK=/путь/к/sdk
make          # build/ps4hddtools.elf
make send PS4_HOST=192.168.0.24
```
Версия задаётся одним местом: `src/version.h`.

## Языки
Веб-страница и приложение PKG используют **одни и те же** файлы переводов: `lang/lang_<код>.json` (сейчас 20 языков: английский, русский, немецкий, французский, испанский, итальянский, португальский, нидерландский, польский, чешский, венгерский, румынский, турецкий, греческий, украинский, шведский, датский, норвежский, финский, индонезийский). Язык веб-страницы выбирается по языку браузера, приложения - по системному языку консоли, оба переключаются в меню.

Чтобы добавить язык: скопируйте `lang/lang_en.json` в `lang/lang_<код>.json`, переведите значения и запустите `python3 tools/check_lang.py` (проверит ключи, подстановки и что все символы есть в шрифте приложения). Больше ничего менять не нужно. Подробности - `lang/README.md`.
