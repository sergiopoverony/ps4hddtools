# PS4 HDD Tools: приложение (PKG)

Экспериментальная оболочка для службы ps4hddtools. **Этап 1**: приложение само запускает службу и показывает на экране консоли список дисков с состоянием. Полный интерфейс (SMART, проверка поверхности) будет добавлен следующими этапами.

## Как это работает

```
приложение (PKG, экран + геймпад)  --HTTP 127.0.0.1:8686-->  служба ps4hddtools (payload под GoldHEN)
```

- При запуске приложение спрашивает службу (`/api/state`). Если службы нет, оно отправляет её ELF (лежит внутри PKG) в BinLoader GoldHEN на этой же консоли (порт 9090) и ждёт, пока она ответит.
- Если запущена служба другой версии, отправляется версия из PKG, а старая копия сама завершается.
- Служба работает отдельно от приложения: если закрыть приложение, она продолжает работать. Выключается кнопкой Options в приложении (или кнопкой в меню веб-страницы).
- Веб-страница (`http://IP:8686/`) продолжает работать как раньше.

## Языки

Переводы общие с веб-страницей службы: файлы `../lang/lang_<код>.json` (20 языков). При сборке `pkg/Makefile` сам копирует их в `assets/misc/` и добавляет `languages.json` (список языков), править в `pkg/` ничего не нужно. Язык берётся из системных настроек консоли (если для него нет файла, например японский, то английский); в меню приложения его можно сменить: на строке «Язык» нажмите Cross или стрелки влево/вправо. Шрифт приложения (DejaVu Sans Mono) покрывает латиницу, кириллицу и греческий, поэтому арабского, иврита, тайского, вьетнамского и CJK нет. Как добавить язык - `../lang/README.md`.

## Управление

| Кнопка | Действие |
|---|---|
| Cross | обновить диски (или запустить службу снова, если она не запустилась или выключена); в меню на строке языка - следующий язык |
| Options | выключить службу (с подтверждением: Cross - да, Circle - отмена) |

## Сборка

Нужен [OpenOrbis PS4 Toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain) и переменная `OO_PS4_TOOLCHAIN` (как для ps4torrent client), а для сборки самой службы (в корне проекта) - `ps4-payload-sdk` и переменная `PS4_PAYLOAD_SDK`.

### Для новичка: с нуля

Если оба тулчейна уже установлены (OpenOrbis распакован в свою папку, `ps4-payload-sdk` - в свою), вот весь путь от клонирования до готового PKG:

```bash
# 1. Клонируем репозиторий (ветка pkg-dev - там живёт приложение)
cd ~
git clone -b pkg-dev https://github.com/sergiopoverony/ps4hddtools.git ps4hddtools_new
cd ps4hddtools_new

# 2. Говорим make, где лежат тулчейны (пути - свои, смотрите, куда распаковывали)
export PS4_PAYLOAD_SDK=/opt/ps4-payload-sdk
export OO_PS4_TOOLCHAIN=/путь/к/OpenOrbis-PS4-Toolchain

# 3. Собираем всё одной командой
cd pkg
make full
```

После успешной сборки в папке `pkg/` появится `IV0000-BREW00089_00-PS4HDDTOOLS00000.pkg` - его и ставим на консоль через GoldHEN (Install PKG).

Если `make full` падает на шаге сборки службы (`make -C ..`) с ошибкой вида `ld.lld: error: cannot find linker script /ldscripts/elf_x86_64.x` - убедитесь, что `PS4_PAYLOAD_SDK` экспортирован (шаг 2), и обновитесь (`git pull`) - эта ошибка была в самом тулчейне `ps4-payload-sdk` (он не всегда подхватывал свой путь сам), и мы обошли её в своём Makefile.

**Проще всего** (если переменные окружения уже выставлены - собирает и службу, и приложение одной командой, без риска получить PKG со старым payload внутри):
```
cd pkg
make full
```

Либо руками по шагам (если нужно собрать только что-то одно):
1. В корне проекта соберите службу: `make` (нужен ps4-payload-sdk) и скопируйте результат в `release/ps4hddtools.elf`: `cp build/ps4hddtools.elf release/ps4hddtools.elf` (в репозитории там уже лежит какая-то версия - **легко забыть обновить её** после правок в службе/версии, тогда PKG соберётся с новым интерфейсом, но со старым payload внутри - версии разойдутся).
2. В папке `pkg/` выполните `make`. Получится `IV0000-BREW00089_00-PS4HDDTOOLS00000.pkg`.
3. Установите PKG на консоль (GoldHEN).

Системные модули (`libc.prx`, `libSceFios2.prx`) Makefile сам находит и копирует из набора OpenOrbis в `pkg/sce_module/` (без них приложение вылетает сразу после заставки). Иконка и фон запуска берутся из `../sce_sys/` (`Icon0.png`, `pic1.png`), баннер из `assets/images/title.png`. Версия приложения всегда равна версии службы (берётся из `../src/version.h`).
