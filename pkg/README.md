# PS4 HDD Tools: приложение (PKG)

Экспериментальная оболочка для службы ps4hddtools. **Этап 1**: приложение само запускает службу и показывает на экране консоли список дисков с состоянием. Полный интерфейс (SMART, проверка поверхности) будет добавлен следующими этапами.

## Как это работает

```
приложение (PKG, экран + геймпад)  --HTTP 127.0.0.1:8686-->  служба ps4hddtools (payload под GoldHEN)
```

- При запуске приложение спрашивает службу (`/api/state`). Если службы нет, оно отправляет её ELF (лежит внутри PKG) в BinLoader GoldHEN на этой же консоли (порт 9090) и ждёт, пока она ответит.
- Если запущена служба другой версии, отправляется версия из PKG, а старая копия сама завершается.
- Служба работает отдельно от приложения: если закрыть приложение, она продолжает работать. Выключается кнопкой Options в приложении (или кнопкой в меню веб-страницы).
- Веб-страница (`http://IP:8686/`) продолжает работать как раньше.

## Управление

| Кнопка | Действие |
|---|---|
| Cross | обновить диски (или запустить службу снова, если она не запустилась или выключена) |
| Options | выключить службу (с подтверждением: Cross - да, Circle - отмена) |

## Сборка

Нужен [OpenOrbis PS4 Toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain) и переменная `OO_PS4_TOOLCHAIN` (как для ps4torrent client).

1. В корне проекта соберите службу: `make` (нужен ps4-payload-sdk) и положите результат в `release/ps4hddtools.elf` (в репозитории там уже лежит готовая версия).
2. В папке `pkg/` выполните `make`. Получится `IV0000-BREW00089_00-PS4HDDTOOLS00000.pkg`.
3. Установите PKG на консоль (GoldHEN).

Системные модули (`libc.prx`, `libSceFios2.prx`) Makefile сам находит и копирует из набора OpenOrbis в `pkg/sce_module/` (без них приложение вылетает сразу после заставки). Иконка и фон запуска берутся из `../sce_sys/` (`Icon0.png`, `pic1.png`), баннер из `assets/images/title.png`. Версия приложения всегда равна версии службы (берётся из `../src/version.h`).
